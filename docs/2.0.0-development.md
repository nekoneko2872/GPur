## 実装の境界

既存の生成器、seed、ノイズの初期化、演算順序を維持します。近似や量子化は使用しません。Paper のイベントとワールドへの変更確定、ディスクへの書込みはCPUに残します。

| 工程 | 今回追加した経路 | 残っている処理 |
| --- | --- | --- |
| ノイズ | Improved / Perlin / Normal / Blended のFP64バッチ計算。既存グラフの静的なノイズ入力を収集し、同じサンプラーと座標ビットが一致する結果だけを元のCPUグラフが使用 | 密度グラフの演算、Spline、動的ShiftedNoiseの終端、非対応ノード、グラフや既存キャッシュの制御 |
| 補間 | 1.1.0 の厳密な非同期補間を継続 | GPU受付失敗時は元のCPU補間 |
| 帯水層 | CPUで初期化済みの中心座標をGPUへ送り、元のループと同じ上位4候補を選択 | 流体状態、圧力、地表参照、流体更新フラグの判定 |
| 地表・構造物・装飾 | 既存のCPU経路を維持 | 計算のGPU移植は未実装 |
| ブロック配置 | 元のCPUループ・変更確定を維持 | GPUから確定ブロック分類を一括受信する経路は未実装 |
| 照明 | 既存のCPU経路を維持 | GPU移植は未実装 |
| 保存 | 既存のCPU経路を維持 | NBT直列化・圧縮のGPU移植は未実装。ディスク書込みはCPUを維持する方針 |

新しい境界は検証用の独立した設定です。既定値は無効です。

```yaml
chunk-generation:
  vanilla-terrain:
    mode: strict
    noise-batches: true
    aquifer-ranking: true
```

`strict` はGPU結果をCPUで全量照合します。性能比較には、厳密照合とワールド一致を確認した後、別の新規ワールドで `verified-exact` を使用します。常時全量照合した実行の速度を、そのままGPU化による速度向上として扱いません。

## 品質の条件

GPUスレッドへ渡すのは数値のコピーだけです。ノイズの乱数初期化と帯水層の位置乱数は元のCPU実装を使用します。帯水層の同距離候補は、元のX/Y/Z訪問順と `>=` の挿入順を維持します。

GPU結果の寿命とCPU側の保持容量を管理し、停止・キャンセル・世代更新時には結果を採用しません。GPU用の配列はCPU操作中の読取りで再利用されません。補間のキャンセルと変更確定を直列化し、処理中にセクションを解放しないようにしています。

ノイズ収集は既知のバニラノードだけを訪問します。未知のプラグイン・カスタムノードを評価・書換えません。元のキャッシュや密度グラフを別の生成ルールへ置換しません。

設定の再読み込みでは、古いGPU結果を無効にして、既に開始したチャンクの生成をCPU側で完了させます。停止時にはチャンクの生成要求を止めてから、外側の生成futureをキャンセルします。これにより、受理済みの実行待ち処理をキューが破棄しても、チャンクの所有権と数値結果を解放できます。GPurのNOISE処理のキャンセルだけをスケジューラの通常キャンセルとして扱い、実際の生成エラーは元のエラー処理へ渡します。

## 帯水層の修正と新しい候補

本番サイズのカーネル試験で、座標`(4,-61,13)`の候補順位3がCPUでは34、GPUでは16となる不一致を再現しました。シェーダーが12での切捨て除算に負数の剰余演算を使用していました。この演算は[GLSL仕様](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html)で未定義です。負数の絶対値を符号なし整数で扱う計算へ変更し、12の倍数となる負の座標や`INT_MIN`でも演算を定義しました。
